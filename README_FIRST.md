# AXM Local Game Hub

Status: **EXPERIMENTAL proof of start**.

This is the small local-play distribution, not the complete AXM Workshop.

## Start on one computer

Double-click `START_GAME_HUB.cmd`.

## Start a family or friend game night

1. Put the host computer and phones on the same trusted Wi-Fi.
2. Double-click `START_LAN_GAME_NIGHT.cmd`.
3. If Windows Firewall asks, allow Node.js only on **private** networks.
4. Choose a game on the host computer.
5. Open the shared game screen.
6. Let each player scan one visible seat QR code.

No account, subscription, cloud sync or internet service is required. LAN mode deliberately exposes the game to devices on the same network, so do not use it on an untrusted public Wi-Fi network.

The games are young and their original `WORKING TEST` or `PLAYABLE ALPHA` labels remain visible. This package proves the route; it does not claim the catalog is finished.
